pantheon-extras

A personal apt repository of useful additions to Pantheon, for elementary OS 8.

Install Source
io.elementary.dock-extras

Dock

elementary's dock with folder stacks and zoom. Replaces io.elementary.dock.

Folder stacks

Drag a folder from Files onto the dock and it opens as a fan, newest file nearest the dock. Right-click a stack to change its view or sort, or to remove it.

Applications grid

The Applications stack shows installed apps as a grid, with app folders as folders. Any stack can be a grid or a fan.

Zoom

Icons near the pointer grow, drawn from the icon theme at the zoomed size. On by default.

gsettings set io.elementary.dock zoom-size 84
gsettings set io.elementary.dock zoom-enabled false
pantheon-paper

Tiling

A Gala plugin for PaperWM-style tiling. Each workspace on the primary monitor is a horizontal strip of columns that scrolls to follow focus.

Columns

New windows open to the right of the focused one. A column can hold several windows; dialogs float. Super+scroll pans the strip.

Keys

Super+arrows        focus
Super+Shift+arrows  move
Super+R             width ⅓ ½ ⅔
Super+M             full width
Super+I / Super+U   slurp / barf
Super+C             centre
Super+Shift+F       float

What it changes

Workspace switching moves to Ctrl+Super+←/→. Half-screen and edge tiling are off, and move-to-monitor is unbound. Keys you have set yourself are kept.

io.elementary.terminal-ghostty

Terminal

elementary Terminal with VTE swapped for libghostty-gtk, a GTK 4 widget on libghostty-vt. Replaces io.elementary.terminal; tabs, themes and paste protection are unchanged.

libghostty-gtk-1-0libghostty-gtk-dev

libghostty-gtk

The terminal widget Terminal uses. It implements the subset of Vte.Terminal that elementary Terminal needs, under GhosttyGtk. libghostty-vt is linked statically; a VAPI is included.

sudo apt install libghostty-gtk-dev
pkg-config --cflags --libs ghostty-gtk-1

Install

On elementary OS 8 (noble, amd64). Install any of the packages.

Add the repository

signed-by limits the key to this repository.

Terminal
$ sudo curl -fsSLo /usr/share/keyrings/pantheon-extras.gpg https://arsfeld.github.io/pantheon-extras/pantheon-extras.gpg
$ echo "deb [signed-by=/usr/share/keyrings/pantheon-extras.gpg] https://arsfeld.github.io/pantheon-extras noble main" \
    | sudo tee /etc/apt/sources.list.d/pantheon-extras.list
$ sudo apt update

Install packages

The dock and tiling take effect at your next login.

Terminal
$ sudo apt install io.elementary.dock-extras
$ sudo apt install pantheon-paper
$ sudo apt install io.elementary.terminal-ghostty

Revert

Reinstalling elementary's packages replaces these. Removing pantheon-paper restores Pantheon's keys.

Terminal
$ sudo apt install io.elementary.dock io.elementary.terminal
$ sudo apt remove pantheon-paper
