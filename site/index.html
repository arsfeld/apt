pantheon-apt

Signed apt repository for elementary OS 8 (noble, amd64). Experimental; not affiliated with elementary or Ghostty. Source: arsfeld/pantheon-apt.

PackageReplacesBuilt from
io.elementary.dock-extras io.elementary.dock arsfeld/elementary-dock (extras)
io.elementary.terminal-ghostty io.elementary.terminal arsfeld/elementary-terminal (libghostty-gtk)
libghostty-gtk-1-0, libghostty-gtk-dev — arsfeld/libghostty-gtk

Install

sudo curl -fsSLo /usr/share/keyrings/pantheon-apt.gpg https://arsfeld.github.io/pantheon-apt/pantheon-apt.gpg
echo "deb [signed-by=/usr/share/keyrings/pantheon-apt.gpg] https://arsfeld.github.io/pantheon-apt noble main" \
  | sudo tee /etc/apt/sources.list.d/pantheon-apt.list
sudo apt update
sudo apt install io.elementary.dock-extras        # takes effect at next login
sudo apt install io.elementary.terminal-ghostty

To go back, install elementary's packages; that removes these:

sudo apt install io.elementary.dock io.elementary.terminal

io.elementary.dock-extras

elementary's Dock with the following added. Everything else is unchanged.

Folder stacks

  • A folder placed after the launchers opens as a fan or a grid.
  • Drag a folder from Files onto the dock to add it. Right-click a stack to change its view and sort order, or to remove it.
  • Downloads sorts newest first, nearest the dock; partial downloads show progress.
  • The Applications stack is a grid of installed apps sorted by name, with app folders (Games, System, …) as folders.
  • The last row opens the folder in Files.

Zoom and sharp icons

  • Icons near the pointer magnify and their neighbours spread apart. On by default.
  • Zoomed or tilted icons are loaded from the icon theme at their on-screen size instead of scaled from 48 px.
gsettings set io.elementary.dock zoom-size 84
gsettings set io.elementary.dock zoom-enabled false

io.elementary.terminal-ghostty

elementary Terminal with VTE replaced by libghostty-gtk, which uses libghostty-vt for parsing and terminal state. Installed as the default terminal.

  • Kitty keyboard protocol, synchronized output, grapheme clustering.
  • OSC 52 clipboard writes (reads are opt-in), including over SSH.
  • Truecolor, styled and coloured underlines, wide characters, OSC 8 hyperlinks.
  • Kept from elementary Terminal: tabs, themes, sudo paste protection, natural copy and paste.

libghostty-gtk

The GTK 4 terminal widget behind the Terminal package. It implements the subset of VTE's Vte.Terminal API that elementary Terminal uses, under the namespace GhosttyGtk; the Terminal port was about ten lines.

  • Renders with GtkSnapshot; handles its own PTY, keyboard, IME, mouse, paste, selection, search, URL matching and OSC 52.
  • libghostty-vt is linked statically. A VAPI is included for Vala.
sudo apt install libghostty-gtk-dev
pkg-config --cflags --libs ghostty-gtk-1

How it's built

Each source repository builds its .debs in elementary's OS 8 container and publishes them as GitHub Releases. This repository's workflow picks up new releases hourly, signs the index, publishes it here, then installs from it in a clean elementary OS 8 container to check the result.
